# Natours

A responsive landing page for an outdoor adventure tours company, built with HTML and modular Sass. This project demonstrates modern CSS techniques, including responsive layouts, animations, card effects, background video, navigation, forms, and popup components.

## Features

- Responsive layout for desktop, tablet, and mobile
- Custom animated navigation
- Tour cards with 3D flip effects
- Story section with background video
- Booking form and popup section
- Sass architecture using variables, mixins, and reusable components
- Optimized images and CSS with vendor prefixes

## Built With

- HTML5
- Sass/SCSS
- CSS3

## Getting Started

```bash
npm install
npm run watch:sass
```

Open `index.html` in a browser. The watcher rebuilds `css/style.css` whenever an SCSS file changes.

To create the production CSS:

```bash
npm run build:css
```
